Android 11+ · 通用操作 Agent

一句话，
让手机自己把事做完。

AutoP 在 Android 手机上看屏幕、动手操作，由大模型规划每一步。屏幕可以从无障碍节点树、端侧视觉模型或视觉大模型读取；点击和滑动优先走节点动作，也可以通过无线调试配对用 shell 注入，等同真实触摸。不需要 root，Android 11 及以上的手机装上就能用。

能做什么

把手机交给它，
你只管说要做什么。

01

一句话下达任务

在对话页或悬浮球里说「把屏幕亮度调到 50%」「在微信里告诉张三明天的会推迟到 4 点」。Agent 列出计划并逐步执行，运行中可以补充指令，也可以一键停止。

02

看懂屏幕

默认走无障碍节点树，成本最低；应用屏蔽节点时换端侧视觉模型，再不够交给视觉大模型。三种方式输出同一种归一化坐标，操作层不关心画面从哪里来。

03

点得稳，滑得稳

优先走系统无障碍节点动作；连接无线调试后，坐标手势走 shell 注入，等同真实触摸，未连接时回落到无障碍注入。按应用记住哪种方式有效，滚动按容器计算距离。

04

到点或到时自己做

手动、定时、条件三种触发。通知到达、App 进入前台、充电、网络变化、解锁都能成为开始信号，带冷却期、每日上限和重复事件去重。

05

悬浮球与执行期

全局悬浮球带圆弧菜单和进度面板；Agent 操作手机时，屏幕四周有随主题色流动的柔光，顶部显示步数胶囊。执行期间触摸盾挡住误触，暂停或停止后立即解除。

06

模型配置由你指定

OpenAI 兼容与 Anthropic 兼容两种协议，不依赖官方 SDK。主模型、视觉模型、轻量模型可以分开分配，Embedding 可关闭。

流程

重复的操作，
沉淀成流程。

用自然语言描述，AI 边思考边生成可预览的步骤草稿；也可以打开悬浮球，在目标应用里正常操作一遍，AutoP 会记录并转成步骤。之后直接运行，不必每次让模型重新推理。

流程执行会核对结果。失败时依次等待、换位置、关闭弹窗、返回、重启应用，仍不行再交回 Agent 接手。

记忆

用得越久，
越懂你的手机。

记忆按目录组织：用户档案、人物、各 App 的操作手册、任务笔记。提示词里只放索引，正文按需读取；检索用路径匹配、全文和向量混合召回。

Agent 可以直接写入记忆，所有写入带版本，可以在「最近变更」里逐条撤销。

界面

干净、直接，
不打断你。

敏感场景硬阻断

支付、转账、密码、授权、删除账号、安装未知应用等场景在执行层拦截，不依赖提示词。命中后暂停任务并通知你手动处理。

数据只去你指定的端点

屏幕文本和截图会发给你配置的模型服务。项目不含统计、崩溃上报等第三方 SDK；想要完全本地，可以把端点指向自己部署的模型。

密钥与操作记录

API Key 经 Android Keystore 加密存放，密码框内容不进入观测和日志。所有动作写入操作记录，可事后查看。

自己装一个

不需要 root，Android 11 及以上即可安装。在 GitHub Releases 下载最新的 app-release.apk；Android 13 及以上侧载后，需要先在应用信息里「允许受限设置」，再开启无障碍服务。
