按坐标点击（真实触摸）。x、y 是内容区 0–1000 坐标，优先直接用观测里元素的 at，不要从截图的像素坐标换算（截图像素不是 0–1000）。
结果里的 hit 是点击发出前该坐标处的元素，和目标不一致说明点偏了。点击后不会自动观测，需要确认结果时调用 observe。
注入模式有两种：shell 注入（等同真实触摸）和无障碍注入（部分应用会忽略）。当前模式见运行状态里的“坐标操作当前模式”，结果里的“执行：…”写明本次实际模式以及回退原因。
observe 发现屏幕没有变化时，先 wait 等页面加载、换一个位置，或改用 tap_node（需要 a11y 观测的 id），不要原样重复点击。
