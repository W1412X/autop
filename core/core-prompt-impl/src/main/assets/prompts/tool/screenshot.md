id: tool.screenshot
version: 5
vars: []
meta:
  param.region: 只截取该区域，{x1,y1,x2,y2} 坐标 0–1000（相对内容区）
  param.mark_point: 落点核对标注，{x,y} 坐标 0–1000（相对内容区），在截图上画十字准星
  param.reason: 截图用途说明，会记录到审计日志
---
截取当前屏幕并返回图片（已隐藏状态栏/导航栏，坐标以可见区为基准）。主要用于核对落点或看像素级细节；如果只是缺少节点信息，先用 observe 的 visual（本机模型、离线、便宜），不要默认用截图代替观测。坐标点击拿不准落点时，传 mark_point 在截图上画出十字准星核对位置，确认命中目标后再用 tap 传 x,y 点击。
