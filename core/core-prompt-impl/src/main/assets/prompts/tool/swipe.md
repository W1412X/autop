  param.x1: 起点横坐标，0–1000

按坐标滑动，坐标同 tap。列表滚动优先用 scroll。结果里的 hit 是滑动发出前起点处的元素。滑动后不会自动观测。
注入模式有两种：shell 注入（等同真实触摸）和无障碍注入（部分应用会忽略）。当前模式见运行状态里的“坐标操作当前模式”，结果里的“执行：…”写明本次实际模式以及回退原因。
