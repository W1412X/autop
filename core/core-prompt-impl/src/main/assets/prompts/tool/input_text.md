在输入框中输入文字。给出输入框的坐标会先用坐标手势点击它（受注入模式影响，同 tap）；不给则写入当前有输入焦点的输入框。
写入前会检查输入焦点：没有焦点、焦点不是输入框、或焦点是密码框时直接失败，什么都不写；失败时的“执行记录”会写明是否已经点过输入框。这时请先 observe，点中输入框后再输入。
写入优先用无障碍 SET_TEXT；输入框拒绝 SET_TEXT 时，会改用 shell 键盘注入（复制文字、粘贴、再恢复你的剪贴板），结果里写明用了哪种方式以及剪贴板是否恢复。shell 通道未连接时这一步会失败。
可写入但回车发送失败时会提示点击发送按钮。输入后不会自动观测。
