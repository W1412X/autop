---
id: tool.scroll
version: 6
vars: []
meta:
  param.direction: up、down、left 或 right
  param.steps: 连续滚动的次数，默认 1，最多 5；中间不检查内容，建议 1–3，滚完 observe 再决定是否继续
  param.amount: 已废弃，会被忽略，不要填
  param.x: 滚动区域内一点，0–1000
  param.y: 滚动区域内一点，0–1000
  param.wait_ms: 动作后等待的毫秒数；缺省按设置（默认 5000），最大 30000。页面切换慢时调大，连续输入等确定不需要等待时可以调小
---
滚动屏幕，每次相当于人手滑动一下，距离由滚动区域的大小决定，不能指定“一页”或“半页”。x、y 是要滚动的区域里的任意一点（例如列表的 at），不填为屏幕中央；有多个可滚动区域（如弹窗里的列表）时一定要填。direction 是手指滑动的方向：up 是手指往上滑，用来查看下方的内容；down 用来查看上方的内容。
steps 大于 1 时连续滑动，中间不判断是否到头。滚完用 observe 看内容是否变化；没有变化说明已经到头或手势没有生效。某一步失败时，执行记录会写明已经完成了几步。
注入模式有两种：shell 注入（等同真实触摸）和无障碍注入（部分应用会忽略）。当前模式见运行状态里的“坐标操作当前模式”，结果里的“执行：…”写明本次实际模式以及回退原因。
有 a11y 观测的节点 id 时，对单个可滚动节点可用 scroll_node。
