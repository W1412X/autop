vars: []
meta:
  param.flow: 要修订的流程名称或 ID
  param.node_id: 要修订的节点 id（就是刚才失败的那一步）
  param.reason: 修订的原因，例如“页面改版后按钮文字变了”
---
用本次任务中成功执行的那一次动作，修订某个流程里的单个节点。适用于流程的某一步失败、你接手把这一步做完之后。

只替换该节点的操作与目标，节点 id、失败处理、前置条件、期望效果都保留。生成的是待确认草稿，用户确认后才生效，原定义会保留为历史版本可回滚。

注意：只用真正完成这一步的那次操作，不要把你返回页面、重开应用的导航动作也算进去。
