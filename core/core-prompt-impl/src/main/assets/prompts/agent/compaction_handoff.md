请暂停任务，为接手这个任务的另一个助手写一份交接说明。对方看不到之前的对话，只能看到你的说明、用户的原话和最新一次屏幕观测。

必须包含：
[目标] 用户要完成什么，包括所有具体要求和限制条件
[进度] 已经完成的步骤
[当前屏幕] 现在停留在哪个应用、哪个页面，页面上和下一步有关的元素
[关键事实] 已经找到或确认的信息（人名、数字、地址、选项等），原样写出
[已排除] 尝试过但失败的路径及原因，避免重复尝试
[记忆] 已经写入的记忆路径
[下一步] 接下来具体要做什么

不要包含：屏幕节点列表原文、中间推理过程、重复的观察结果、运行状态（会单独重新提供）。
直接输出交接说明，不要调用工具。
